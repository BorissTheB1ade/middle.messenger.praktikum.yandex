# Проект Messenger - Спринт 4

## Описание

На данном этапе добавлены тесты основных классов проекта: роутера, компонента, модуля отправки запросов
Настроен прекоммит с использованием Husky, проведен аудит пакетов и исправлены все конфликты версий

## Функционал

Функционал не изменился по сравнению со Спринт 3


## Запуск проекта

1. Склонируйте репозиторий
2. Установите зависимости:
```bash
   npm install
   ```
3. Запуск в dev режиме:
```bash
   npm run dev
   ```
4. Сборка и автозапуск проекта после сборки:
```bash
   npm run start
   ```

## Другие команды

1. Запуск тестов:
```bash
   npm run test
   ```
2. Запуск аудита пакетов:
```bash
   npm audit
   ```
