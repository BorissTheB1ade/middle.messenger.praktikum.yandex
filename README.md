# Проект Messenger - Спринт 3

## Описание

На данном этапе реализовано SPA (Single Page Application) на Typescript.
SPA представляет собой простой месссенджер, с минимальным дизайном

*Пользуйтесь навигационными ссылками на страницах*

## Функционал

1) Реализована страница чатов с возможностью отправки сообщений, выбора и добалвения чатов, добавления и удаления пользователей из чата и удаления самих чатов
2) Реализована возможность создания и редактирования учетной записи в т.ч смена пароля
3) Отправка и получение сообщений реализорваны на WebSocket


## Запуск проекта

1. Склонируйте репозиторий
2. Установите зависимости:
```bash
   npm install
   ```
3. Запуск в dev режиме:
```bash
   npm run dev
   ```
5. Сборка и автозапуск проекта после сборки:
```bash
   npm run start
   ```
